# 📝 BLOG_HUB (Medium Clone)

A **full-stack blogging platform** built using **MERN stack (MongoDB, Express.js, React, Node.js)** with **OAuth authentication**, allowing users to create, edit, save, and share posts – just like Medium.

---

## 🚀 Features

- 🔑 **Authentication**
  - OAuth login (Google)
  - JWT-based sessions
- 🖊 **Blog Management**
  - Create, edit, and delete posts
  - Add categories & tags
  - Rich text editor for writing posts
- 👤 **User Profiles**
  - View and edit profile information
  - Display user bio, avatar, and social links
- ❤️ **Social Features**
  - Like, comment, and follow writers
  - Save/bookmark posts for later
- 🏷 **Dynamic Categories**
  - Filter posts by category
  - Personalized "For You" feed based on followed topics
- 📷 **Image Support**
  - Upload banner images for posts (stored in Firebase / Cloudinary)
- 🔗 **Share & SEO**
  - Share posts on social media
  - SEO-friendly URLs for posts

---

## 🛠️ Tech Stack

**Frontend:**  
- React (with Hooks & Context API)
- Tailwind CSS for styling
- React Router for navigation
- Axios for API calls

**Backend:**  
- Node.js + Express.js (REST API)
- MongoDB (Mongoose ODM)
- JWT for authentication
- OAuth 2.0 integration (Google/GitHub)

**Other Services:**  
- Cloudinary for image storage
- Vercel / Render for deployment
